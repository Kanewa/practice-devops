# Кейс-задача №5 — Анализ программы валидации ввода (task2.py)

## Введение

В данной кейс-задаче представлен анализ программы `task2.py` — реализации программы получения положительного целого числа от пользователя с вычислением его факториала. Программа решает две взаимосвязанные задачи: корректную валидацию пользовательского ввода и эффективное математическое вычисление с использованием стандартной библиотеки Python.

---

## 1. Цель программы

Программа `task2.py` создана с двойной целью.

**Первичная цель** — получить от пользователя корректное положительное целое число, обеспечивая при этом полную защиту от некорректного ввода. Программа должна продолжать запрашивать ввод до тех пор, пока пользователь не введёт данные в правильном формате, при этом каждый раз давая понятное объяснение допущенной ошибки.

**Вторичная цель** — вычислить факториал полученного числа, используя оптимизированную стандартную библиотеку, и вывести результат в понятном виде с дополнительной информацией для больших чисел.

Таким образом, программа служит наглядным примером двух ключевых навыков начинающего программиста на Python: написание надёжного кода взаимодействия с пользователем и использование стандартных библиотек для решения вычислительных задач.

---

## 2. Основные функции программы

Программа состоит из трёх функций, каждая из которых несёт чётко определённую ответственность:

### `получить_число_от_пользователя()`

Основная функция валидации. Реализует бесконечный цикл `while True`, который прерывается только при получении корректного ввода с помощью оператора `return`. Выполняет три последовательные проверки:

1. Проверка на пустоту строки
2. Преобразование в целое число (через `int()` в блоке `try/except`)
3. Проверка на положительность (число > 0)

Каждая неудачная проверка сопровождается конкретным информативным сообщением и командой `continue` для возврата к началу цикла.

### `вычислить_факториал(n)`

Функция вычисления факториала. Принимает целое число, предварительно проверяет его неотрицательность (защитная проверка), затем делегирует вычисление функции `math.factorial()`. Снабжена полноценным docstring с описанием параметров, возвращаемого значения и возможных исключений.

### `main()`

Точка входа и «дирижёр» программы. Выводит заголовок, краткое объяснение понятия факториала с примером, затем последовательно вызывает функцию получения ввода и функцию вычисления. Обрабатывает потенциальные исключения `ValueError` и `OverflowError`. Для больших чисел дополнительно выводит количество цифр в результате.

---

## 3. Интерфейс программы

Программа использует минималистичный, но структурированный консольный интерфейс (CLI):

**Заголовок** отделён горизонтальными разделителями из символов `=` и содержит название программы. Это сразу сообщает пользователю, с чем он работает.

**Вводная информация** объясняет понятие факториала и приводит конкретный пример (`5! = 1 × 2 × 3 × 4 × 5 = 120`). Это делает программу понятной даже для человека, незнакомого с математической нотацией.

**Запрос ввода** сформулирован предельно ясно: «Введите положительное целое число:». Никакой лишней информации — только то, что нужно пользователю.

**Сообщения об ошибках** всегда начинаются со слова «Ошибка:» для единообразия, содержат конкретное описание проблемы и, когда это уместно, повторяют обратно введённое значение (`Вы ввели: -3`), чтобы пользователь понял, что именно было некорректным.

**Вывод результата** отделён разделителем и представлен в привычной математической нотации: `5! = 120`.

---

## 4. Алгоритм работы программы

Алгоритм программы линейный с циклом валидации:

1. Вывод заголовка и пояснения.
2. **Цикл получения числа:**
   a. Запрос строки у пользователя.
   b. Если строка пустая → вывод ошибки, переход к п.а.
   c. Попытка преобразования в `int`. Если исключение → вывод ошибки, переход к п.а.
   d. Если число ≤ 0 → вывод ошибки, переход к п.а.
   e. Если все проверки пройдены → возврат числа.
3. Вызов `math.factorial(число)` в блоке `try/except`.
4. Вывод результата в формате `N! = результат`.
5. Если N > 20 → дополнительный вывод количества цифр.
6. Завершение программы.

## 5. Валидация и обработка исключений

Это ключевая часть программы, заслуживающая детального рассмотрения.

### Многоуровневая валидация

Валидация реализована как последовательность барьеров в функции `получить_число_от_пользователя()`:

**Барьер 1 — пустая строка:**
```python
if not ввод:
    print("Ошибка: ввод не может быть пустым.")
    continue
```
Обрабатывает случай, когда пользователь нажал Enter без ввода чего-либо.

**Барьер 2 — нечисловой ввод:**
```python
try:
    число = int(ввод)
except ValueError:
    print(f"Ошибка: '{ввод}' не является целым числом.")
    continue
```
Перехватывает `ValueError`, возникающий при попытке преобразовать нечисловую строку или дробное число в `int`. Вывод повторяет введённое значение, чтобы пользователь понял, что именно было неверным.

**Барьер 3 — отрицательное число или ноль:**
```python
if число <= 0:
    print(f"Ошибка: число должно быть положительным.")
    continue
```
Проверяет семантическое условие задачи: факториал определён для неотрицательных чисел, но задание требует положительного числа (> 0).

### Обработка ошибок вычисления

В функции `main()` вычисление обёрнуто в `try/except`:

```python
try:
    результат = вычислить_факториал(число)
except ValueError as e:
    print(f"Ошибка вычисления: {e}")
except OverflowError:
    print("Ошибка: число слишком велико.")
```

`ValueError` ловит случай передачи отрицательного числа (защитная проверка внутри `вычислить_факториал`). `OverflowError` предусмотрен как потенциальная проблема — в Python она практически не возникает из-за поддержки длинной арифметики, но такая обработка делает код более переносимым и правильным с точки зрения инженерной культуры.

## 6. Пользовательский опыт

Программа демонстрирует хороший уровень внимания к пользователю:

**Обучающий подход.** Вводная информация с примером факториала помогает пользователю понять, что вычисляет программа. Это снижает когнитивную нагрузку.

**Никаких технических сообщений.** Пользователь никогда не увидит стек вызовов или технические сообщения Python. Все ошибки перехватываются и переводятся в понятный язык.

**Конкретность сообщений об ошибках.** Каждое сообщение объясняет конкретную проблему, а не даёт общий ответ «неверный ввод». Это помогает пользователю немедленно исправить ошибку.

**Дополнительная информация.** Для больших факториалов (N > 20) программа дополнительно сообщает количество цифр в результате, что добавляет познавательный элемент (например, 100! содержит 158 цифр).

## 7. Производительность

Использование `math.factorial()` вместо собственной реализации цикла — ключевое решение для производительности.

`math.factorial()` реализована в C-коде интерпретатора CPython и использует значительно более быстрые алгоритмы, чем простой цикл умножения (в частности, алгоритм разделяй и властвуй для очень больших чисел). Разница становится заметной при вычислении факториалов больших чисел (N > 1000).

Python поддерживает длинную арифметику «из коробки» — целые числа в Python не ограничены разрядностью машинного слова и могут содержать сколь угодно много цифр. Это означает, что программа корректно вычислит, например, 10000! (число с более чем 35000 цифрами), хотя и не мгновенно.

В функции `вычислить_факториал()` присутствует собственная проверка на отрицательность (`if n < 0: raise ValueError`), которая дублирует проверку в функции получения ввода. Это «защитное программирование»: функция не доверяет своим клиентам и проверяет предусловия самостоятельно. Такой подход повышает надёжность при возможном повторном использовании функции.

## 8. Расширяемость

Программа спроектирована с хорошей расширяемостью:

**Разделение ответственности.** Функции `получить_число_от_пользователя()` и `вычислить_факториал()` независимы друг от друга. Это позволяет:
- Заменить `math.factorial()` на другую реализацию без изменения логики ввода
- Использовать функцию валидации ввода в других программах
- Добавить вычисление других функций (перестановки, сочетания) поверх существующего ввода

**Возможные расширения:**
- Добавление режима множественного вычисления (цикл до команды выхода)
- Сохранение истории вычислений в файл
- Вывод промежуточных шагов вычисления
- Поддержка вычисления двойного факториала (N!!)
- Добавление графического интерфейса на tkinter
