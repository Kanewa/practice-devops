# Кейс-задача №3 — Анализ программы для вычисления факториала(task2.py)

## Введение

В данной кейс-задаче представлен анализ программы `task2.py` — реализации классической текстовой игры «Угадай число» на языке Python. Программа демонстрирует практическое применение базовых концепций программирования: работу с генератором случайных чисел, организацию игровых циклов, валидацию пользовательского ввода и управление состоянием игры.

### Цель
Создать программу, которая получает от пользователя положительное целое число, вычисляет его факториал с использованием оптимизированной библиотечной функции и выводит результат, обеспечивая корректную обработку всех возможных ошибок ввода.

### Основные функции
Программа выводит вводную информацию о понятии факториала, запрашивает ввод числа у пользователя, проверяет корректность введённого значения, вычисляет факториал через math.factorial() и выводит результат. При вводе числа больше 20 дополнительно отображается количество цифр в результате.

### Интерфейс
Консольный ввод/вывод. При запуске программа выводит заголовок, краткое объяснение понятия факториала с примером вычисления, приглашение ввести число, информативные сообщения об ошибках и итоговый результат в формате n! = результат.

### Алгоритм
Программа запрашивает у пользователя ввод и последовательно проверяет его: сначала на пустоту, затем на возможность преобразования в целое число через int(), затем на то, что число положительное. При несоответствии любому из условий выводится сообщение об ошибке и запрос повторяется. При корректном вводе число передаётся в calculate_factorial(), после чего результат выводится на экран.

### Валидация и обработка исключений
Валидация выстроена в три уровня. Первый — проверка на пустой ввод через if not user_input. Второй — перехват ValueError при попытке преобразовать строку в целое число через int(), что отсекает текст, спецсимволы и дробные значения. Третий — явная проверка number <= 0 с информативным сообщением, включающим введённое значение. Дополнительно функция calculate_factorial() защищена собственной проверкой на отрицательное значение через raise ValueError, что делает её безопасной при использовании независимо от get_number_from_user().

### Пользовательский опыт
Каждый тип ошибки сопровождается отдельным конкретным сообщением: пустой ввод, нечисловое значение и неположительное число обрабатываются и описываются независимо. При ошибке ввода программа не завершается — цикл while True с continue возвращает пользователя к повторному запросу. Для больших чисел выводится количество цифр в результате, что делает вывод более наглядным.

### Адаптивность и расширяемость
Код разделён на независимые функции: get_number_from_user() отвечает за валидацию, calculate_factorial() — за вычисление, main() — за оркестрацию и вывод. Благодаря этому легко добавить ограничение диапазона допустимых значений, пакетную обработку нескольких чисел или поддержку нуля как отдельного допустимого случая без изменения остальной логики.

### Производительность
Используется math.factorial() — функция реализована на C внутри интерпретатора Python, что значительно быстрее самостоятельно написанной рекурсии или цикла. Python корректно работает с целыми числами произвольной точности, поэтому переполнения не возникает ни при каких значениях.

### Документация и тестирование
Функции снабжены аннотациями типов (n: int, -> int), что улучшает читаемость и упрощает статический анализ кода. Для полноценного тестирования необходимо проверить корректные вводы (например, 1, 5, 100), некорректные (текст, дробные числа, спецсимволы, пустая строка, ноль, отрицательные числа) и граничные случаи. Каждый из этих сценариев должен либо вернуть правильный результат, либо вызвать повторный запрос ввода с соответствующим сообщением.

### Дополнительные требования
Валидация реализована через последовательную проверку трёх условий с использованием try/except для перехвата ошибок преобразования типов. Такой подход корректно обрабатывает все предсказуемые пользовательские ошибки и при этом сохраняет читаемость кода.
